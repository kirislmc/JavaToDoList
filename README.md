# JavaToDoList

## About This Project

This is my fifth Java project!
- **Structured Terminal Output:** Formatting single entries into a clean, numbered list for easy readability.
- **Resource Management:** Proper initialization and closing of system resources.

## Features

- **Quick Task Capture:** Prompt-based entry for your top 5 daily goals.
- **Automatic Numbering:** Converts your inputs into an organized, numbered list.
- **Multi-Word Support:** Write full sentences or short notes per task.
